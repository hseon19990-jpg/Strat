عرض الطلبات (النسخة 2)
=====================
التطبيق: استخرج الملف فوق مجلد المشروع مع الحفاظ على المسارات ووافق على الاستبدال، ثم أعد تشغيل البوت.
الجدول الجديد (order_inspect_snapshots) يُنشأ تلقائياً عند التشغيل.

للعضو:  💼 حسابي ومحفظتي ← 📦 عرض طلباتي
        تحت كل طلب: 🔄 تتبّع (حالة مباشرة) و 🔁 إعادة (نفس الرابط أو رابط جديد، والدفع بالمجوهرات كالمعتاد)
        إشعار اكتمال الطلب صار يحوي الخدمة والكمية وزر «إعادة الطلب».
للمالك: ⚙️ الإعدادات ← 🛍 الخدمات والطلبات ← 📊 الطلبات
        • الجدول: الطلب │ المشتري │ المدفوع │ الحالة │ الباقي/الواصل + التالي/رجوع
        • 🎛 فلاتر: الحالة (قيد التنفيذ/مكتمل/جزئي/ملغي) + الفترة (24س/7أيام/30يوماً) + مشتري محدد
        • 📤 تصدير CSV (يحترم الفلتر الحالي، حتى 5000 طلب، يفتح بالعربية في Excel)
        • 📈 تقرير 24 ساعة (الآن) + تقرير يومي تلقائي الساعة 9:00 بتوقيت بغداد (🔔 زر التفعيل/التعطيل)
          لتغيير الساعة: ضع في جدول settings المفتاح orders_report_hour بقيمة 0-23.

إصلاحات: جدول «فحص الطلب» وربط إدخال كوده في messages.py كانا ناقصين في النسخة المرفوعة.

الملفات الجديدة: bot_app/orders_view.py, tests/test_orders_view.py
الملفات المعدّلة: bot_app/__init__.py, application.py, callbacks.py, database.py, messages.py, security.py, services.py, ui.py
التحقق: python tests/test_orders_view.py   (وفحصت الاستعلامات فعلياً على Postgres)
