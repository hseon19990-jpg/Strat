# 🤖 مساعد الكود الذكي

بوت تيليجرام يعدّل الكود على GitHub تلقائياً باستخدام Gemini AI.

## متغيرات البيئة المطلوبة على Railway

| المتغير | المصدر |
|---|---|
| `ASSISTANT_BOT_TOKEN` | BotFather على تيليجرام |
| `GEMINI_API_KEY` | [aistudio.google.com](https://aistudio.google.com) مجاني |
| `GITHUB_TOKEN` | نفس التوكن الحالي |
| `OWNER_ID` | ID حساب تيليجرام الخاص بك |
| `TARGET_REPO` | `hseon19990-jpg/Strat` (افتراضي) |
| `TARGET_FILE` | `telegram-bot/bot.py` (افتراضي) |

## خطوات النشر على Railway

1. أنشئ **Service جديد** في مشروعك على Railway
2. اختر **"Deploy from GitHub repo"** ← نفس الريبو
3. في إعدادات الـ Service، غيّر **Root Directory** إلى `ai-assistant`
4. أضف المتغيرات أعلاه في تبويب **Variables**
5. انتظر النشر ← البوت يعمل تلقائياً

## طريقة الاستخدام

أرسل للبوت أي تعليمة بالعربية أو الإنجليزية:

> أضف زر "إحصاءات" في القائمة الرئيسية

> غيّر رسالة الترحيب لتكون أكثر ودية

> عندما يرفض المالك الإيميل أرسل للمستخدم سبب مفصّل

البوت سيعرض معاينة للتعديل ويطلب تأكيدك قبل الرفع.

## الحدود المجانية لـ Gemini

- 15 طلب/دقيقة
- 1,500 طلب/يوم
- مجاني تماماً بدون بطاقة ائتمان
