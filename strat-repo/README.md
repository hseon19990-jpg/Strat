# SMMMAIN Telegram Bot

تم تقسيم البوت الكبير إلى وحدات حسب المسؤولية مع الحفاظ على نقطة التشغيل
القديمة:

```bash
python bot.py
```

## خريطة الملفات

- `bot.py` — نقطة التشغيل وسياسة إعادة التشغيل فقط.
- `bot_app/shared.py` — الاستيرادات، الإعدادات، تحويل الجلسات، وخادم health.
- `bot_app/database.py` — اتصال PostgreSQL وتهيئة الجداول وعمليات قاعدة البيانات
  المشتركة.
- `bot_app/users.py` — المستخدمون، النقاط، الإحالات، الإعدادات، والمشرفون.
- `bot_app/accounts.py` — مخزون أرقام Telegram وفحص الحسابات والجلسات.
- `bot_app/referrals.py` — القنوات الإجبارية، الكابتشا، مهام الإحالة، والطلبات
  المرتبطة بها.
- `bot_app/security.py` — تسجيل الدخول، 2FA، تدوير الجلسات، والمراقبات الخلفية.
- `bot_app/services.py` — تكامل لوحات SMM وعمليات الخدمات والطلبات.
- `bot_app/ui.py` — القوائم، الأزرار، خدمات الصور والقصص، ورسائل المالك.
- `bot_app/onboarding.py` — بدء المستخدم، التحقق، وأوامر المالك الأولية.
- `bot_app/messages.py` — استقبال النصوص والملفات والرسائل غير المدعومة.
- `bot_app/callbacks.py` — معالجة أزرار Inline Callback.
- `bot_app/payments.py` — الدفع، أحداث القنوات، البث، وفحص حالة الطلبات.
- `bot_app/application.py` — إنشاء التطبيق وتسجيل handlers والمهام المجدولة.

## طريقة إضافة ميزة

1. حدد المجال الأقرب للميزة.
2. ضع الدوال الجديدة في الملف المناسب.
3. لا تضف منطقًا جديدًا إلى `bot.py`.
4. شغّل فحص الصياغة قبل النشر:

```bash
python -m compileall -q bot.py bot_app
```

## ملاحظة التوافق

تستخدم الحزمة طبقة تحميل مشتركة مؤقتة للحفاظ على العلاقات القديمة بين الدوال
أثناء فصلها. لذلك لن تحتاج إلى إعادة كتابة كل الاستدعاءات دفعة واحدة. مع إضافة
ميزات جديدة يمكن نقل المجالات إلى خدمات مستقلة تدريجيًا.
